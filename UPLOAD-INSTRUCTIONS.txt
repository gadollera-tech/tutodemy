TutoDemy Notification Bell — Public Website Patch

IMPORTANT INSTALLATION ORDER
1. First run the private Supabase SQL file: NOTIFICATION-BELL-UPGRADE.sql.
2. Then upload this public patch to GitHub.

GITHUB UPLOAD
1. Extract this ZIP.
2. Open the extracted TutoDemy-Notification-Bell-Update-Patch folder.
3. Upload every file and folder INSIDE it to the root of the existing TutoDemy repository.
4. Choose Replace for matching files.
5. Make one commit only.
6. Wait for GitHub Pages to become green.
7. Open https://tutodemy.net and press Ctrl + Shift + R.
8. On an installed phone app, close and reopen TutoDemy once after deployment.

DO NOT upload the private SQL setup ZIP or SQL file to GitHub.
