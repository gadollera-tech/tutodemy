TUTODEMY ACCOUNT + TUTOR MARKETPLACE SETUP

1. Open Supabase SQL Editor.
2. Run docs/SUPABASE-COMPLETE-INSTALL.sql.
3. Create your normal TutoDemy account through auth.html.
4. Add that account to public.admin_users using the SQL example in docs/SUPABASE-SETUP-GUIDE.md.
5. Set Supabase Site URL to https://tutodemy.net and allow https://tutodemy.net/**.
6. Upload all website files to the GitHub repository root.
7. Test tutor application → admin approval → booking → manual payment confirmation → delivery → completion.

The browser uses only the public Supabase Project URL and publishable key.
Never upload a service_role key, sb_secret key, database password, or payment secret.
