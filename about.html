ABOUT TUTODEMY

A learning and tutor marketplace built for Filipino students.

The project combines years of tutoring experience, educator networks, exam-preparation resources, and a practical goal: make guided learning easier to access and organize.

THE VISION

From practice bank to learning community.

TutoDemy is designed as more than a static reviewer website. The long-term platform can connect students, parents, tutors, original resources, practice analytics, and eventually secure subscriptions.

The platform supports learner accounts, tutor applications, private verification, approved public profiles, booking requests, and progress tools in one organized learning space.

WHAT IS ALREADY WORKING

Learning and marketplace features included now.

NOW

Practice engine

2,580-question combined CET and DOST-SEI-style bank, randomized sets, timers, navigation, scoring, explanations, and attempt history.

NOW

Reviewer library

Searchable reviewer modules with domain-linked practice.

NOW

Tutor directory

Role-based tutor onboarding, private verification uploads, admin approval, public profiles, schedule requests, and verified reviews.

Email/password login, learner/parent and tutor roles, protected account data, cloud progress, and private tutor-document storage.

ADMIN-CONFIRMED

Tutoring payments

Payment instructions are provided after tutor acceptance, and each transaction is confirmed before the session is marked paid.
