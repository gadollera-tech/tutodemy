## Account synchronization

Save the following for signed-in learners:

- selected bank or wave
- random seed
- exact question IDs
- shuffled choice order
- answers and flags
- current section
- remaining section time
- submitted sections
- result breakdown

## Premium security

Free and Premium fields in the JSON are labels only.

Real Premium protection requires server-side entitlement checks. Browser JavaScript cannot securely hide paid question records.

## Repository safety

Do not upload the original reference PDFs to a public repository.
