TutoDemy Mobile + Installable App Patch

VERSION: 20260809-pwa1

WHAT THIS ADDS
- Responsive mobile safeguards for phones and tablets
- Installable Progressive Web App (PWA) support
- Android/Chrome/Edge install prompt when supported
- iPhone/iPad Add to Home Screen instructions
- Standalone app display with TutoDemy icons
- A lightweight offline fallback page
