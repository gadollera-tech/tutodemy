# Content Review Checklist

Every public question should pass these checks:

## Accuracy

- Correct answer independently solved or verified
- Every numerical value and unit checked
- No second defensible answer
- Explanation matches the keyed answer
- Diagram labels and visual sequence checked

## Language

- Clear stem
- Age-appropriate vocabulary
- Standard English or Filipino form
- No unnecessary ambiguity
- Distractors are plausible but incorrect

## Originality

- New wording
- New values and context
- New answer choices
- No copied commercial passage
- No recalled or leaked examination item
- Original or permission-cleared figure

## Metadata

- Subject
- Domain
- Topic
- Difficulty
- Free or Premium designation
- Estimated solving time
- Reviewer and version date

## Publication status

Recommended workflow:

```text
Draft → Internal Check → Subject Review → Language Review → Verified → Published
```
