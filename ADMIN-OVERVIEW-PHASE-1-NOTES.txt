TutoDemy Learning PH — Admin Overview Phase 1

This release adds a secure platform-wide administrator overview.

Public website files changed:
- admin.html
- css/style.css
- js/admin.js
- js/marketplace-api.js
- service-worker.js

Private setup required:
- Run ADMIN-OVERVIEW-PHASE-1.sql in Supabase SQL Editor before relying on the new totals.
- Do not upload the SQL file or private setup ZIP to GitHub.

Overview definitions:
- Total registered accounts: all rows in public.profiles.
- Learner-only accounts: non-admin profiles whose current role is learner.
- Approved tutors: tutor_profiles rows with status approved.
- Active users this month: distinct users with exam activity, active-session updates, booking activity, or booking messages during the current Philippine calendar month.
- Platform commission earned: commission_ledger commission generated only after a paid booking is completed.
- Pending tutor payout: tutor net earnings in commission_ledger that are still marked pending.

This overview is operational reporting, not formal accounting. It does not deduct taxes, hosting costs, refunds processed outside the database, or other business expenses.
